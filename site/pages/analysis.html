The work

Analysis

You run a supplied Python workflow from the command line. There is no notebook. One command fits every model on the training rows, scores it on the test rows, and writes the results your app reads.

The protocol

Each dataset is split once, before anything else: 80% training {{help training-set}} and 20% test {{help test-set}}, stratified. The split is the split column in each CSV, and every model uses it.

  1. Commit Before results in DECISIONS.md {{help decisions-md}}, before you see any result.
  2. python -m analysis fits each model on the training rows only.
  3. It then gives every training and test row a probability, and writes both, with the training and test AUROC, to results/.
  4. It also copies DECISIONS.md to results/decisions.json, so rerun it after you write your recommendations.

The commands

Run them from the starter folder, with your environment active.

  • Fill in Design choice and AI use last too, once your app is built: one thing you chose to show or leave out for your clinical lead, and one AI suggestion you turned down.

The files the workflow exports

Your app reads only these files {{help results-files}}. Commit and push results/ so your hosted app can load them. Every probability is rounded to 4 decimals before any metric is computed, so m11 recomputes the exported numbers exactly.

FileHolds
results/<key>.jsontrain and test: the row_id and y (the label) of every row, and the counts. For each model in models: train_p and test_p (one probability per row) and train_auroc and test_auroc. The starter's files hold the baseline only.
results/decisions.jsonYour parsed DECISIONS.md answers, which sections are complete, your word count, and recommendations (the lines your app shows at the top).
Example: read your results in Python 
import m11

res = m11.load("diabetes")
p, y = m11.preds(res, "logreg")               # test probabilities and labels
c = m11.confusion(p, y, 0.5)                  # {"tp", "fn", "fp", "tn"}
print(m11.metrics(c)["sensitivity"])          # None means undefined
print(m11.auroc_summary(res)["rf"])           # {"train", "test", "gap"}

What check.py verifies

  • The data files match their fingerprints in data/manifest.json.
  • Your results cover exactly the supplied training and test rows, so no model was fitted on test rows.
  • knn is a Pipeline object, with scaling inside, and no model's settings have changed.
  • No outcome or ID column is used as a predictor.
  • The default logreg test AUROC matches the reference within ±0.005.
  • Every exported AUROC matches the one recomputed with m11.
  • All three sections of DECISIONS.md are complete, exported and committed.

Every failure says what to fix in one sentence. Fix the first one, then run it again.
