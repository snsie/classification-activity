Publish & back up

You need both: a public app link {{help public-link}} that anyone can open, and a public GitHub repository {{help github-backup}}. Publish the untouched starter first, in step 1.

Both are required

A repository alone isn't a hosted app, and a hosted app alone isn't a backup. Your repository is also what you submit.

Your app is a Streamlit app (streamlit_app.py), hosted free on Streamlit Community Cloud. Your Python analysis runs on your computer, and the hosted app only reads the files it exported to results/.

1. Put the starter on GitHub

  1. Download and unzip the starter from Data & files.
  2. Install Python 3.11 or newer and git. In the starter folder, run: 
    python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python check.py --stage setup
  3. On GitHub, create a new public repository (for example judge-the-model). Don't add a README; the starter has one.
  4. In the starter folder, run: 
    git init -b main
git add .
git commit -m "Starter"
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main

2. Publish the untouched starter

  1. Go to share.streamlit.io and sign in with GitHub.
  2. Click Create app, then pick your repository, branch main and file streamlit_app.py.
  3. Click Deploy. It installs the pinned packages in requirements.txt; list any package you add there too.

To try it on your computer first: streamlit run streamlit_app.py

3. Test it in a private window

  • Open your link in a private or incognito window. It must load without signing in.
  • Switch datasets and models in every section.
  • Put your link on the first line of README.md, then commit and push.

4. Push updates

Commit and push whenever a section starts working, after each run of the analysis, and after your final checks. Commit results/ too: your hosted app reads it from GitHub.

git add .
git commit -m "Section 2 works"
git push

Streamlit updates a minute or two after you push. A commit on your laptop is not a backup until it's pushed. Never commit passwords, tokens or API keys.

Troubleshooting

The app says there are no results
  • Check that results/ is committed and pushed: open your repository on GitHub and look for results/diabetes.json.
  • Load results through m11.load(...), which finds results/ next to m11.py.
The Streamlit app is asleep

Apps on Streamlit Community Cloud sleep after a few days without visitors. Open the link and click the button to wake it. Open it again just before you submit.

Streamlit says "ModuleNotFoundError"

Add the missing package to requirements.txt with a pinned version, commit and push. Streamlit redeploys automatically.

Nothing works

Run the app on your computer with streamlit run streamlit_app.py and read the first error. Tell your instructor if your link breaks after you submit.
