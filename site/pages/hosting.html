Publish & back up

You need both: a public app link {{help public-link}} that anyone can open, and a public GitHub repository {{help github-backup}}. Publish the untouched starter first, in step 1.

Both are required

A repository alone isn't a hosted app, and a hosted app alone isn't a backup. Your repository is also what you submit.

Choose Streamlit or Node.js

The starter has the same four plain sections twice. Pick the one you'd rather build in, and build and host only that one. Both earn the same credit. Either way, your Python analysis runs on your computer, and the hosted app only reads the files it exported to results/.

If you like, delete the app you don't use (streamlit_app.py, or web/ and package.json). Keep m11.py: the analysis and check.py use it.

1. Put the starter on GitHub

  1. Download and unzip the starter from Data & files.
  2. Install Python 3.11 or newer and git, plus Node.js 20 or newer if you chose Node. In the starter folder, run: 
    python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python check.py --stage setup
  3. On GitHub, create a new public repository (for example judge-the-model). Don't add a README; the starter has one.
  4. In the starter folder, run: 
    git init -b main
git add .
git commit -m "Starter"
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main

2. Publish the untouched starter

Streamlit: Streamlit Community Cloud

  1. Go to share.streamlit.io and sign in with GitHub.
  2. Click Create app, then pick your repository, branch main and file streamlit_app.py.
  3. Click Deploy. It installs the pinned packages in requirements.txt; list any package you add there too.

To try it on your computer first: streamlit run streamlit_app.py

Node.js: Render

  1. Go to render.com and sign in with GitHub.
  2. Click New, then Web Service, and pick your repository.
  3. Set Language Node, Branch main, Build Command npm install, Start Command npm start and Instance Type Free.
  4. Click Deploy. Your link ends in .onrender.com. The starter needs no npm packages; list any you add in package.json.

To try it on your computer first: npm start, then open http://localhost:8766/

3. Test it in a private window

  • Open your link in a private or incognito window. It must load without signing in.
  • Switch datasets and models in every section.
  • Put your link on the first line of README.md, then commit and push.

4. Push updates

Commit and push whenever a section starts working, after each run of the analysis, and after your final checks. Commit results/ too: your hosted app reads it from GitHub.

git add .
git commit -m "Section 2 works"
git push

Your host updates a minute or two after you push. A commit on your laptop is not a backup until it's pushed. Never commit passwords, tokens or API keys.

Troubleshooting

The app says there are no results
  • Check that results/ is committed and pushed: open your repository on GitHub and look for results/diabetes.json.
  • Streamlit: load results through m11.load(...), which finds results/ next to m11.py.
  • Node: fetch results/<name>.json the way the starter's load() in web/app.js does, and start the app with npm start from the repository's top folder.
The Streamlit app is asleep

Apps on Streamlit Community Cloud sleep after a few days without visitors. Open the link and click the button to wake it. Open it again just before you submit.

Streamlit says "ModuleNotFoundError"

Add the missing package to requirements.txt with a pinned version, commit and push. Streamlit redeploys automatically.

The Render app takes a minute to open

Free Render apps sleep after 15 minutes without visitors, and the next visit wakes them in about a minute. Open your link once just before you submit.

The Node app shows a blank page or no numbers

Open the browser's developer console (F12) and read the first error: it names the file and line in web/. If Render's log says Cannot find module, add the package to package.json and push.

import lightgbm fails on a Mac

If the message mentions libomp, run brew install libomp, then try again.

Nothing works

Run the app on your computer (streamlit run streamlit_app.py or npm start) and read the first error. Tell your instructor if your link breaks after you submit.
