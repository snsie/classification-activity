The two datasets

Each CSV has the same layout: row_id; split (train or test; 80/20, stratified, seed 0); the predictors; and target (1 = the positive class). Blank cells are missing values.

  • Use the split column. Every model learns from the same training rows and is scored on the same test rows; never reshuffle.
  • Check “When is it known?” for every column {{help when-known}}. A predictor must exist at the prediction point.
  • One row per person in every dataset, so each person's records are already kept together {{help records-together}}.

Using the starter

The starter has the same plain app twice; you build one of them. Streamlit: you edit streamlit_app.py, which reads results/ through the metric helpers in m11.py; run it with streamlit run streamlit_app.py. Node.js: you edit web/app.js, which reads results/ through the same helpers ported to web/m11.js; run it with npm start. Have your AI agent read {{dl AGENT_BRIEF.md}} first.
