The three datasets

Each CSV has the same layout: row_id; split (dev or test; 80/20, stratified); fold (1–5 for development rows, stratified, seed 0); the predictors; and target (1 = the positive class). Blank cells are missing values.

  • Use the fold column. Every model uses these folds {{help fold}}; never reshuffle.
  • Check “When is it known?” for every column {{help when-known}}. A predictor must exist at the prediction point.
  • One row per person in every dataset, so each person's records are already kept together {{help records-together}}.
